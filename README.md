# Psplit

Psplit is a lightweight PDF splitter utility.

## What it does

- Splits a source PDF into smaller PDF files.
- Supports splitting by page ranges.
- Keeps output files in page order for easy downstream use.

## Typical workflow

1. Choose an input PDF.
2. Define how you want to split pages (for example, single pages or ranges).
3. Run the splitter.
4. Collect the generated PDFs from the output location.

## Expected input/output

- **Input:** One PDF document and split instructions (pages or ranges).
- **Output:** One or more PDF files containing the requested page segments.
